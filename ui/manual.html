上传文件

先把文件「添加附件」到本次运行，再按页面正常顺序点上传。写法对照下载：先点入口，再写入。

点击上传，点击上传文件，上传

指令里含「上传」时，执行期间不会弹出系统选文件窗口；跑完自动恢复。

找不到按钮：使用页面探针

图标按钮、同名控件多，或 点击某某 无效时：显示浏览器 → 页面探针 → 复制指令。

优先用带文字/图标名的指令（稳定）；同类很多时才加 #N（页面一变编号可能变，需重探）。

点击图标:close-circle 点击图标:close-circle#2

图标名须带冒号（: / ：）。探针从 class、data-icon、aria-label / title、SVG、图片名等抽取；无明确名时用业务 class 兜底（如 el-upload--picture-card）。与普通 点击确定 互不影响。

业务脚本（本机 Excel / 文件）

业务脚本用 Rhai 语言编写，在 设置 → 脚本 管理；菜谱或首页用 脚本名称 [参数…] 调用。只读写本机文件，不连浏览器。

列表怎么看

脚本列表按折叠分组：内置、示例、私有、公开。右侧可打开《业务脚本编写指南》《AI 生成提示词》文档预览；预览窗也可「在浏览器中打开」。

先跑通内置示例

样例表是内置模板「学生各科分数」（姓名：青禾/白鹭…；班级：东湖班/西岭班）。可直接发送：

脚本示例复制成绩表 脚本示例预览成绩 东湖班 脚本示例核算总分 脚本示例筛及格 60 东湖班 脚本示例你好 东湖班 青禾

参数怎么传

  • ARGS：名称后面的整段原串（已 trim）
  • 推荐分词：arg(0)、arg(1, "默认")、require_arg(0, "用法…")（空格分词，从 0 起）

常用数据流

  1. 用 find_template / copy_template 把模板拷到本次运行的 files/
  2. read_table 读表，或 open_workbook 写回
  3. 结果写到 files/…，并 track_output，方便在运行产物里找到
脚本合并考勤数据 山西阳泉 2026-06 脚本考勤数据对比 陈倩

考勤类为正式内置脚本；参数含义见设置里该脚本的备注。

写簿常用能力

打开工作簿后可读表名、建页、复制整页：

  • wb_sheet_names(wb)
  • wb_new_sheet(wb, "汇总") — 新建空白 sheet
  • wb_copy_sheet(wb, "源表", "副本") — 复制整页（含内容与样式）
  • ws_get_cell / ws_set_cell（行列从 1 起）· wb_save
不会写 Rhai 时：把《AI 生成提示词》整段贴到豆包 / 千问等作系统设定，再描述业务；生成结果粘贴到「设置 → 脚本」即可。
脚本名不要互为前缀（例如同时有「核算」和「核算总分」容易歧义）。菜谱里逗号、点号等需按规则转义。

Excel 模板

在 设置 → 模板 管理可复用的 xlsx。列表同样分为 内置 / 示例 / 私有 / 公开。

  • 示例：如「学生各科分数」，给教学脚本共用
  • 内置：如「考勤汇总模板」，给合并考勤等正式脚本使用
  • 私有 / 公开：云端同步的个人或团队模板

脚本里 find_template 返回的是文件名，必须先 copy_template(文件名, "files/…") 再读写。

飞书多维表格

先在受控浏览器中打开目标多维表格，再发送指令。操作对象始终是浏览器当前打开的表格。

按条件查询

飞书查询，项目名称=鹤山

筛选写法（字段名须与表头一致，多条件用逗号或空格分隔，默认同时满足）：

  • 字段=值 — 等于
  • 字段!=值 — 不等于
  • 字段has值 — 包含
  • 字段!has值 — 不包含
  • 字段empty — 为空
  • 字段!empty — 不为空
飞书查询，提报状态=未提报，项目名称has鹤山，备注!has作废，资料链接empty

用熟以后

AI 帮你写步骤

开启首页顶部的 AI 增强 后，可以直接描述任务，例如：

打开考勤系统，查询本月考勤并下载报表

执行前请检查 AI 生成的步骤，尤其是登录、删除、提交和导出操作。

用飞书远程启动任务

在 设置 → 飞书 绑定后，私聊机器人发送技能名即可。电脑须开机且 webclaw 在运行。

自定义业务脚本

在 设置 → 脚本 新建或编辑；需要样板 API 时打开编写指南 / AI 提示词。浏览器负责下载与网页操作，脚本负责合并、筛选、生成结果文件。

遇到问题

点击没有反应

先确认页面已加载完成，再增加 等待2；仍无效时使用页面探针复制准确指令。

内容输入到了错误的框

不要只写 输入内容，改成带字段名的写法，例如 输入月份=2026-06。

没有找到下载文件

点击导出后必须加 等待下载60（等到文件落盘再继续；任务期间下载会自动截获）。文件在 webclaw 的运行产物中，不要只看 Chrome 下载栏。

上传时弹出了系统选文件窗口

确认指令里写了「上传」，并按 点击上传，点击上传文件，上传 的顺序执行；上传前先「添加附件」。

页签序号对不上

序号按浏览器从左到右计数。关掉或新开标签后重新数一遍，再写 页签#N。

页面要求验证码

图形验证码：在弹出窗口中填写并提交。滑块或其它需人工操作：写 人机验证，在浏览器中完成后再点「我已完成」；登录时若自动检测到滑块也会提示。

脚本报「未找到模板」

到 设置 → 模板 确认文件已同步；脚本里先 copy_template 再读写。示例可先跑 脚本示例复制成绩表。

脚本与网页步骤混在一起失败

确认脚本名存在且参数用空格分隔；脚本步骤不需要浏览器已启动，但若前面有网页步骤仍需 Debug Chrome。

任务跑错了

立即点击 停止。修改指令后，从头重新运行。

浏览器不在前台

点击 显示浏览器。不要关闭由 webclaw 启动的 Debug Chrome。
