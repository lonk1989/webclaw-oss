# webclaw-lite Skill

本机轻客户端 Skill：AI 读 [SKILL.md](./SKILL.md)，按 [CLI.md](./CLI.md) 调 `webclaw-lite`。

| 文件 | 作用 |
|------|------|
| [SKILL.md](./SKILL.md) | 助手编排（安装 / run / HITL） |
| [CLI.md](./CLI.md) | 命令与 JSONL 契约 |
| [MOUNT.md](./MOUNT.md) | 各 AI 工具如何挂载本 Skill |
| `scripts/install.ps1` | Windows 安装 |
| `scripts/install.sh` | macOS/Linux 安装 |
| `scripts/human_reply.ps1` | 人机回填（可选封装） |
| `scripts/run_recipe.ps1` | 跑菜谱（可选封装） |

静态站同步目录见仓库 `static/webclaw-lite/`（发布时上传）。
