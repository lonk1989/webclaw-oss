# 业务脚本（Rhai）

**设置 → 脚本** 编写；菜谱调用 `脚本名称 [参数…]`。处理本机文件/Excel，也可发 HTTP；**不连浏览器 DOM**。

样例数据：内置模板 **「学生各科分数」**（青禾/白鹭… · 东湖班/西岭班；列：姓名/班级/语数英科）。示例可直接跑。

```text
脚本示例预览成绩 东湖班
脚本示例核算总分
脚本示例筛及格 60 东湖班
脚本示例HTTP GET
```

- `ARGS` 整段原串；推荐 `arg(0)` / `arg(1, "默认")` / `require_arg(0, "用法…")`（空格分词，0 基）
- 输出写 `files/` + `track_output`；模板用 `find_template` / `copy_template`

### HTTP 速查

```rhai
// 简写：成功返回 body 字符串；非 2xx 抛错
let body = http_get(url);
let body = http_get(url, headers);
let body = http_post(url, body);
let body = http_post(url, headers, body);
let body = http_put(url, body);           // 或带 headers
let body = http_patch(url, body);
let body = http_delete(url);              // 或 (url, headers) / (url, headers, body)

// 通用
let body = http_request("GET", url, headers, "");
let ex = http_exchange("GET", url, headers, "");  // #{ status, ok, body }，4xx 不抛

let headers = http_headers(["Content-Type", "application/json", "Authorization", "Bearer xxx"]);
let obj = json_parse(body);
let raw = json_stringify(obj);
```

## 骨架（核算）

```rhai
/// 用法：脚本示例核算总分 [班级]
let class_filter = arg(0);
let tpl = find_template_optional("^学生各科分数\\.xlsx$", "");
if tpl == "" { throw "未找到模板"; }
copy_template(tpl, "files/学生各科分数.xlsx");
let t = read_table("files/学生各科分数.xlsx", ());
// col_index / to_num 累加 → wb_save + track_output
print("完成");
```

## 注意

脚本**无浏览器 DOM / XPath**（那是「断言」）；缺文件用 `find_file_optional`；菜谱里 `,` `.` 需转义；脚本名勿互为前缀。

- **字符串 trim**：内置 `s.trim()` 原地修改且返回 `()`；需要新串请用 `str_trim(s)`，不要写 `let x = s.trim()`（否则会报 `len (())`）。
- **保留字**：不要用 `match` 等作变量名（会报 `reserved keyword`）。
- 去空白比较也可用：`let x = to_str(v); x.trim(); if x == "目标" { … }`
- **HTTP**：默认超时 60s；令牌/密钥勿写死在公共菜谱，可用参数或 `files/` 配置文件。
